# Testing the Test

Interactive simulator accompanying the research paper *Testing the Test* — calibrating statistical significance thresholds under asymmetric error costs.

**Live simulator:** https://maisiecu-web.github.io/testing-the-test/

The whole simulator is a single self-contained file, `index.html`; open it in any modern browser.
